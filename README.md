# 大欅旅館（ookeyaki-ryokan-web）

帝国妖異対策局の本部「大欅旅館」を、PC のブラウザで歩き回れる 3D の Web アプリです。
館内では局長・Hachi・不破寺真九郎・市目瞭子の 4 人が、時刻に合わせて暮らしています（館にいるのは同時に 3 人まで）。
話しかけたり、触れたり、VR 機器で館に入ったりできます。

**遊ぶ: https://teikokuyouitaisakukyoku.github.io/ookeyaki-ryokan-web/**

（初回は約 45〜52MB を読み込みます。誰が出かけているかで変わります。2 回目以降はブラウザのキャッシュで速くなります）

## 動作環境

| 項目 | 通常モード（PC） | 通常モード（スマホ） | VR モード |
|---|---|---|---|
| 端末 | Windows / Mac の PC（キーボードとマウス） | Android スマホ（タッチ操作） | Windows PC と、PC につないだ VR 機器 |
| ブラウザ | Chrome / Edge / Firefox / Safari の最近の版 | Chrome | Chrome または Edge |
| 性能の目安 | メモリ 8GB 以上。GPU のメモリを約 600MB 使う | 軽い素材（画像 512px）を使い、GPU のメモリは約 150MB | VR 対応の単体 GPU |

- スマホは、指で操作する端末だと自動で判定して、軽い素材とタッチ操作に切り替えます（PC で確認するときは URL に `?mobile=1`）。moto g53s（Android・Chrome）の実機で、読み込み・動きの滑らかさ・操作・発熱に問題がないことを確認しています。iPhone（Safari）は未確認です。
- Quest 単体のブラウザには対応していません。
- VR モードは https のページ（または自分の PC 上の localhost）でだけ動きます。

## 遊び方

### 通常モード

| 操作 | 内容 |
|---|---|
| 画面をクリック | 開始（マウスで視点を動かせるようになる） |
| W A S D | 移動（Shift で走る） |
| マウス | 視点 |
| Esc | カーソルを戻す（操作案内を表示） |
| 1〜9・[ ] | 出発点へ移動 |
| Space | 話しかけられたときに返事をする |
| V | カーソルを点 ／ 手に切り替える |
| F5 | 撮影（3D 画面を PNG で保存） |
| Enter | お知らせのリンクを開く |
| Tab | 手帳（限定プリン事件の証拠・できごと図鑑）を開く／閉じる |

- **会話**: 住人の正面まで近づくと話しかけてきます。3 秒以内に Space かクリックで返事をすると、雑談やお知らせ（作品のリンク）を話します。
- **タッチ**: 手のカーソル（V）で住人をクリックすると、部位（頭・胸・お腹・足・腕・手）ごとに反応します。手・腕は、押したまま動かすと引っ張れます。

### スマホ

| 操作 | 内容 |
|---|---|
| 左下のスティック | 移動（いっぱいに倒すと走る） |
| 画面をドラッグ | 視点 |
| 住人をタップ | 触れる（部位ごとに反応） |
| 手・腕を長押し | つかむ。そのまま視点を動かすか歩くと引っ張れる |
| 画面をタップ | 話しかけられたときの返事 |
| 光っている物をタップ | 拾う（限定プリン事件の証拠） |
| 右上の［手帳］［撮影］［メニュー］ | 手帳・撮影（PNG で保存）・操作案内 |

### VR モード

画面右下の［VR開始］を押すと VR モードに入ります。押さなければ通常モードのままです。

| 操作 | 内容 |
|---|---|
| 左スティック | 移動 |
| 右スティック | 30° ずつ向きを変える |
| トリガー | 返事（真九郎を問い詰めているときは、集めた証拠を順に突きつける） |
| グリップ | 住人の手・腕をつかんで引っ張る |

- 空間の手（手のひらの光る球）で住人に触れると反応します。光っている物（事件の証拠）に触れると拾えます。
- 会話は顔の前のパネルに表示します。お知らせのリンクは、通常モードで開けます。

### 限定プリン事件

毎日、局長の冷蔵庫から限定プリンが消えます。犯人はいつも真九郎です。

1. その日はじめて住人に話しかけると、事件が始まります。
2. 証拠を 3 つ集めます。住人に話を聞くと手に入る証言と、館内に落ちている光る物（照準を合わせてクリック／タップで拾う）があります。どこを探せばよいかは手帳に出ます。
3. 真九郎に話しかけると言い訳をするので、それを崩す証拠を選んで突きつけます。違う証拠では効きません。
4. 言い訳を 3 つ崩すと白状して、解決です。翌日はまた別の言い訳と証拠の事件になります。

### できごと図鑑

決まった時間に決まった場所へ行くと、住人のいつもと違う姿が見られます（朝の素振り、夕焼けとお茶、ネトゲのレイドなど 22 種）。そのときに話しかけると図鑑に記録されます。曜日限定のものや、夜中に寝ているところを起こすと記録されるものもあります。手帳で、記録したものと、まだ見ていないものの時間帯を確かめられます。

進み具合（解決した数・図鑑）は、遊んでいるブラウザに保存されます。

### 住人の一日

時刻は、遊んでいる PC の時計に合わせて進みます。

| 住人 | 時間帯 | 様子 |
|---|---|---|
| 局長 | 23:00〜5:00 | 自室（201）で就寝。近づくと起きる |
| 不破寺真九郎 | 23:00〜5:00 | 自室（202）で就寝。近づくと起きる |
| Hachi | 1:00〜4:00 | 自室（206）で待機 |
| 市目瞭子 | 23:00〜5:00 | 自室（203）にこもる（館内には出てこない） |

それ以外の時間は、館内を決まった道順で歩き、立ち止まり、席に座ります。
5:00〜23:00 は、2 時間ごとにひとりずつ出かけます。出かける住人は玄関から坂道へ出ていき、入れ替わりに出かけていた住人が帰ってきます。帰ってくる住人のモデルはそのときに読み込むので、最初の読み込みは 3 人分で済みます。
空の明るさと色も時刻に合わせて変わります（朝焼け・昼・夕焼け・宵・夜）。日の出と日の入りの時刻は、東京のおおよその時刻で季節に合わせて動きます。
URL の末尾に `?time=23:30` のように付けると、その時刻から始められます。

## 開発

Node.js 22 が必要です。

```sh
npm ci          # 依存パッケージを入れる
npm run dev     # 開発サーバー（http://localhost:5173/）
npm run build   # 本番用のビルド（dist/ に出力）
```

`main` ブランチに push すると、GitHub Actions がビルドして GitHub Pages に公開します（`.github/workflows/deploy.yml`）。

### 素材を差し替えたとき

| コマンド | 内容 |
|---|---|
| `npm run optimize-stage` | 舞台 `assets/stage/OokeyakiRyokan.glb` から軽量版を作る（PC 用 `.web.glb`・スマホ用 `.mobile.glb`） |
| `npm run optimize-vrm` | `assets/characters/*.vrm` から軽量版を作る（PC 用 `.web.vrm`・スマホ用 `.mobile.vrm`。画像だけ WebP 化） |
| `npm run build-nav` | 住人の歩行データ `assets/stage/nav.json` を作り直す（舞台を変えたとき。数分かかる） |

公開サイトに載るのは軽量版だけで、元の `.glb` / `.vrm` は配信物に含めません。
開発サーバーで `?stage=full` を付けると、元の素材で表示して見比べられます。
